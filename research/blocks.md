## Notes
- Tower storeys: 43/44/44 (Barbican Living, Historic England list text); CTBUH and Wikipedia say 42. Height 123 m is CTBUH architectural height, identical for all three.
- Bunyan Court flat count (69) is derived from flat numbering; floors disagree between source page (7) and list text (6).
- Station: only John Trundle Court, Lauderdale Tower and Cromwell Tower have a station relation stated in sources; other blocks are null for station.
- Blake Tower: converted 2015-16 per Barbican Living, not 2017 as in the brief. Covered by the same list entry, but physically on Fann Street. Milton Court / The Heron added (not listed).
- Golden Lane Estate is separate (listed 1997); only Great Arthur House's list entry (1021945) was retrieved.
- "Barbican Terrace" is not a block name on Barbican Living, the Barbican Association or City of London lists.
- Photos where the Commons category had no file titled with the block name are flagged in photo_note.
