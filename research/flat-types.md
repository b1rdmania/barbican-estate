# Barbican flat types - digest

Full data: `flat-types.json` (190 type records, 47 listing mentions). Researched 2026-10-10.

## Rules
- Number + letter (1A, 8C): tower flat; letter = side of the triangular tower.
- F/P/M + number + letter (F2A, P2A, M3B): North Barbican (F studio/flat, P penthouse, M maisonette).
- Number only (20, 109): South Barbican terrace flat or mews house.
- Number + H (35H): mirror image of that type.
- Source: https://www.barbicanliving.co.uk/plans/explanation-of-flat-types/ (resident site, not the City).

## How many types
- City of London guidelines: "some 140" (https://www.cityoflondon.gov.uk/assets/Services-Environment/spd-barbican-estate-listed-building-management-guidelines-volume-II.pdf). Orazi book and Telegraph repeat 140.
- Barbican Living documents 128 original types. Thomas Michael says "over 80". Exact number UNCERTAIN; the 140 vs 128 gap is unexplained.
- Later conversions: Frobisher Crescent (32 types, numbered x.y) and Blake Tower (30, names are m2 area, invented by Barbican Living, not City types - they collide with original numbers).
- Original estate: 2,014 flats; our per-type counts sum to 1,995 (19 unaccounted).
